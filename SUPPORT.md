# Getting help

Forge is operated by Flash, and its maintainers answer on a best-effort basis.

- **Questions and account help:** write to [cashu@getflash.io](mailto:cashu@getflash.io).
- **Bugs:** open an issue in the repository it concerns.
- **Vulnerabilities:** report them privately, as [SECURITY.md](SECURITY.md) describes.
- **Your wallet app:** ask the wallet's own project; Forge works with any Cashu wallet.
- **Reserves:** the [reserves report](https://forge.flashapp.me/reserves) is updated every hour.
